# MYST

霧の向こうにしまう、自分だけの写真ストレージ。スマホのホーム画面に追加して使うWebアプリ（PWA）です。

## 機能
- パスコードロック（写真はこの端末の中だけにAES-GCMで暗号化保存。サーバーには送らない）
- フォルダ別保管、一覧の霧（ぼかし）表示
- コラージュ：写真Aに写真Bを重ねる／背景透過・切り抜き／テキスト追加
- 偽パスコード：別サイト・アプリへ移動、またはダミー金庫を開く
- 「撮影」で写真アプリに残さず直接保管
- 暗号化したままのバックアップ書き出し・読み込み

## 構成
- `index.html` アプリ本体（1ファイル完結）
- `sw.js` オフライン対応
- `manifest.webmanifest` / アイコン ホーム画面用
- `netlify.toml` Netlify公開設定
